# 金利君 (Kinri-kun)

住宅ローン返済シミュレーターと家計診断機能を持つWebアプリです。ローンの返済計画を可視化し、家計の長期的な見通しをサポートします。

---

## 機能概要

- **ローンシミュレーター** — 借入条件・金利・返済方式を設定してグラフで可視化
- **家計診断** — 教育費・資産・ライフイベントを含めた長期資産推移を確認
- **保存済み一覧** — シミュレーションを名前付きで保存・読み込み・複製

---

## セットアップ

### 必要な環境

- Node.js 18 以上

### インストールと起動

```bash
# 依存パッケージをインストール
npm install

# Prisma クライアント生成（スキーマ変更後は必ず実行）
npx prisma generate

# データベースを初期化（初回のみ / スキーマ変更後は npx prisma db push を実行）
npx prisma db push

# （任意）マイグレーションを作成したい場合
npx prisma migrate dev --name init

# 開発サーバーを起動
npm run dev
```

ブラウザで http://localhost:3000 を開いてください。

## 使い方

### Tab 1 — ローンシミュレーター

#### 1. ローン条件を入力する（左上フォーム）

| 項目 | 説明 |
|------|------|
| 借入金額 | 100万円単位で入力（例: 3000 = 3000万円） |
| 返済期間 | 1〜50年 |
| 返済方式 | **元利均等**（毎月の返済額が一定）/ **元金均等**（元金が毎月一定、利息は逓減） |
| 5年ルール | 変動金利で金利が変わっても5年間は返済額を固定する |
| 125%ルール | 5年ごとの見直し時、新返済額を前回の125%以内に抑える |

**金利適用期間テーブル**で複数の金利期間を設定できます。期間が返済期間全体をカバーしていないとエラーが表示されます。

例:
```
1〜10年: 0.5%（固定期間）
11〜35年: 1.5%（変動想定）
```

#### 2. 収入・生活費を入力する（右上フォーム）

| 項目 | 説明 |
|------|------|
| 夫/妻の年収 | 万円単位 |
| 年収上昇率 | 毎年の昇給率（デフォルト 2%/年） |
| 月間生活費 | 万円単位（デフォルト 20万円） |

#### 3. グラフを確認する

- **サマリーカード** — 合計返済額・利息総額・元金と利息の割合（ドーナツグラフ）
- **ローン返済グラフ** — 月次返済額の推移（折れ線）と年次元金/利息の内訳（積み上げ棒）
- **キャッシュフロー** — 年ごとの収入・返済・生活費・手残り。手残りがマイナスの年は赤色で警告

#### 4. 保存する

画面右上の「保存」ボタンを押すと名前を付けて保存できます。

---

### Tab 2 — 家計診断

ローンシミュレーターで入力したローン条件を元に、家計全体の長期見通しを作成します。

#### 資産・投資情報

| 項目 | 説明 |
|------|------|
| 夫/妻の現在資産 | 万円単位 |
| 月間投資額 | 毎月の積立投資額（万円） |
| 平均利回り | 投資の想定年利（%） |

#### ライフイベント

ローン返済期間中に発生する大きな支出を登録します。デフォルトで以下が設定されています（内容・金額・時期は自由に変更可）。

| イベント名 | デフォルト金額 | デフォルト時期 |
|-----------|--------------|--------------|
| 車購入 | 300万円 | 5年目 |
| 家電買い替え | 50万円 | 10年目 |
| 自宅リフォーム | 200万円 | 15年目 |

「行を追加」で任意のイベントを追加できます。

#### 子ども教育費シミュレーション

「+ 子どもを追加」で子ども一人ずつ登録します。

| 項目 | 選択肢 |
|------|--------|
| 名前・生まれ年 | 自由入力 |
| 保育園〜高校 | 公立 / 私立 |
| 大学 | 国立 / 私立文系 / 私立理系 |

年間教育費は文部科学省の調査データを基準に自動計算されます。年ごとの教育費推移がグラフで確認できます。

#### 資産推移グラフ

資産残高（緑）とローン残債（赤）の推移を折れ線グラフで表示します。ライフイベントや子どもの入学時期はオレンジの縦線マーカーで示されます。

---

### Tab 3 — 保存済み一覧

保存したシミュレーションをカード形式で一覧表示します。

| 操作 | 説明 |
|------|------|
| 詳細表示 | Tab 1 にデータを読み込んで再確認・編集 |
| 複製 | 「（コピー）」付きで同じ内容を複製 |
| 削除 | 確認後に削除 |
| 名前編集 | カード上のタイトルをクリックして直接編集 |

## 開発者向けコマンド

```bash
npm run dev          # 開発サーバー起動 (localhost:3000)
npm test             # ユニットテスト実行（計算ロジック）
npm run test:e2e     # E2Eテスト実行（Playwright、開発サーバーが自動起動）
npm run build        # プロダクションビルド

# Prisma / DB
npx prisma generate  # Prisma クライアントを生成（スキーマ変更後に必須）
npx prisma db push    # スキーマをデータベースに反映（軽量・即時反映）
npx prisma migrate dev --name <name>  # マイグレーションを作成・適用（履歴管理が必要な場合）
npx prisma studio     # DB ブラウザを起動 (http://localhost:5555)
```
