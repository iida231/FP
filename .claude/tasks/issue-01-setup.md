## 概要

Next.js 14 + TypeScript + Tailwind CSS + Recharts + Prisma + SQLite の開発環境を構築する。

## タスク

- [ ] `npx create-next-app@14` でプロジェクト作成（TypeScript・Tailwind有効化）
- [ ] Recharts をインストール (`npm install recharts`)
- [ ] Prisma を初期化し SQLite をデータソースに設定
- [ ] `localhost:3000` が起動することを確認
- [ ] `npx prisma db push` が正常に実行できることを確認
